# Grammar Cat

可爱、简洁的英语语法学习与翻译训练软件原型。

## 本地预览

这是一个无需安装依赖的静态原型。在项目根目录执行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 已完成

- 首页视觉设计与 Grammar Cat 猫咪元素。
- 「语法精讲」和「翻译测试」两个主要入口。
- 今日 30 题学习目标和未来 AI 答疑接口的产品占位。
